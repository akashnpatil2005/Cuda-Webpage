# Cuda – Agency Landing Page

A responsive single-page website for a creative agency, built with plain HTML5 and CSS3 (no JavaScript). Icons come from Font Awesome via CDN.

## Sections

- Hero with navigation and call-to-action
- Services (Branding, Design, Development, Rocket Science)
- Team with social icons
- Skills (circular progress images)
- Portfolio with filter buttons
- About / testimonials
- Contact form
- Footer links

## Structure

```
├── index.html
├── index.css
└── assets/   (logo, backgrounds, icons, photos)
```

## Run

Keep the three items above in one folder and open `index.html` in a browser. An internet connection is needed only for the icons.

## Responsive

- Mobile: default layout
- Tablet: `768px+`
- Desktop: `1024px+`

## Notes

The hamburger menu, portfolio filters and contact form are visual only and need JavaScript or a backend to work.
